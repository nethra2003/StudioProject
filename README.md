# Studio Interior Design Website
Overview

Studio Interior Design Website is a responsive web-based interior design studio application developed using Django. The project provides users with an interactive platform to explore the studio, learn about its services and history, view completed projects, and navigate through different sections using a clean and modern interface.

The application is structured using reusable Django templates, organized backend components, and integrated static resources such as CSS, JavaScript, and images to create an engaging user experience.

Features
Responsive interior design studio website interface
Modern and user-friendly homepage
Home, About, Services, Projects, and Contact sections
Studio history and company information section
Project showcase for interior design work
Dynamic page rendering using Django
Reusable HTML templates and components
Static file management for CSS, JavaScript, and images
User-friendly navigation system
Backend URL routing and request handling using Django views
SQLite database integration
Technologies Used
Backend: Django, Python
Frontend: HTML5, CSS3, JavaScript, Bootstrap
Database: SQLite
Development Tools: VS Code / PyCharm

Installation Steps
1. Clone the Repository
git clone https://github.com/your-username/StudioProject.git
2. Navigate to Project Directory
cd StudioProject
3. Create Virtual Environment
python -m venv env
4. Activate Virtual Environment
Windows
env\Scripts\activate
Linux / Mac
source env/bin/activate
5. Install Required Packages
pip install -r requirements.txt
6. Apply Migrations
python manage.py makemigrations
python manage.py migrate
7. Run the Development Server
python manage.py runserver

Open the application at:

http://127.0.0.1:8000/
